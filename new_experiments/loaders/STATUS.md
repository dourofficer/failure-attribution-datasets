# Loader status (Nov 2026)

Every `loaders/<slug>.py` exposes `load(limit=None, **kw) -> list[record]` (schema in `common/schema.py`), runs standalone as
`python3 -I loaders/<slug>.py` from `new_experiments/`, and is registered in `loaders/__init__.py`. All records of all 18
slugs pass `common.schema.validate`; ids are unique within each slug; `from loaders import load; load(slug, limit=5)` works for
every slug. Numbers below come from a full load of every slug (memtrace loaded one graph file at a time).

Agent-label match = share of records with both an `error_agent` and an `error_steps` label where
`steps[error_steps[0]]['agent']` (base name, case-insensitive) equals `labels.error_agent`. Because `make_record` sorts
`error_steps`, `error_steps[0]` is always the *earliest* labelled step; where the dataset's primary label is not the earliest
(agentrx root cause, trail HIGH-impact, searchauditbench critical message, mp_bench majority step) the primary index is kept in
`labels.extra` and the match against it is given in parentheses.

## Cross-cutting notes
- `make_record` sorts `error_steps`, so "root cause first" cannot be encoded in the list; the primary index is always in `labels.extra` (`root_cause_idx`, `primary_idx`, `critical_idx`, `earliest_majority_step`).
- Nothing is truncated in loaders except memtrace variable values (10k chars each, as specified).
- Content is never empty except for a few hundred steps whose source message is empty (e.g. longrca 237, aegis 152, mast 122, traceelephant 14 calls that returned only tool_calls with no text -- those still carry the `Action:` line unless the call had neither).
- Outcome: `fail` for every record unless the dataset has successes (agenthallu, failure_as_process, horizon, trajerrbench rewards) ; None for mast_data, trail and embodied horizon.
- Datasets that could not be loaded: none.
