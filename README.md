# Report layout

`main.tex` (the dataset survey) includes one directory per section; dataset sections (Sections 3–6) have one subdirectory per dataset. `8_proposals/proposals.tex` is a separate document built by the same `build.sh` after `main.tex`.

```
report/
  main.tex, preamble.tex, build.sh, WRITER_GUIDE.md, main.pdf (survey), proposals.pdf (standalone research proposals)
  1_intro/intro.tex
  2_overview/overview.tex, figures/fig_*.pdf, tables/tbl_d_*.tex
  3_core/
    who_and_when/  (who_and_when.tex, traj.tex, figures/, refs.bib)
    traceelephant/  (traceelephant.tex, traj.tex, figures/, refs.bib)
    mp_bench/  (mp_bench.tex, traj.tex, figures/, refs.bib)
    who_and_when_pro/  (who_and_when_pro.tex, traj.tex, figures/, refs.bib)
    longrca/  (longrca.tex, traj.tex, figures/, refs.bib)
    agentrx/  (agentrx.tex, traj.tex, figures/, refs.bib)
    symtrace/  (symtrace.tex, traj.tex, figures/, refs.bib)

  4_injected/
    tracertraj/  (tracertraj.tex, traj.tex, figures/, refs.bib)
    aegis/  (aegis.tex, traj.tex, figures/, refs.bib)
    correct_error/  (correct_error.tex, traj.tex, figures/, refs.bib)
    agenterrata/  (agenterrata.tex, traj.tex, figures/, refs.bib)

  5_taxonomy/
    mast_data/  (mast_data.tex, traj.tex, figures/, refs.bib)
    trail/  (trail.tex, traj.tex, figures/, refs.bib)

  6_related/
    agenterrorbench/  (agenterrorbench.tex, traj.tex, figures/, refs.bib)
    searchauditbench/  (searchauditbench.tex, traj.tex, figures/, refs.bib)
    failure_as_process/  (failure_as_process.tex, traj.tex, figures/, refs.bib)
    trajerrbench/  (trajerrbench.tex, traj.tex, figures/, refs.bib)
    agenthallu/  (agenthallu.tex, traj.tex, figures/, refs.bib)
    memtrace/  (memtrace.tex, traj.tex, figures/, refs.bib)
    horizon/  (horizon.tex, traj.tex, figures/, refs.bib)
    megarca_mix/  (megarca_mix.tex, traj.tex, figures/, refs.bib)
  7_recommend/recommend.tex
  8_proposals/
    proposals.tex      standalone document (own \title, TOC, bibliography); shares preamble.tex; references into the survey resolve via xr-hyper from build/main_labels.aux (build/main.aux minus \bibcite, written by build.sh) and link to main.pdf
    preliminaries.tex  working definition (boxed definitions/assumptions), Table tab:vocab, shared data engine Table tab:engine
    p1_perturbation.tex, p2_hazard.tex, p3_training.tex, p4_lifecycle.tex, p5_reroll.tex   one file per proposal, same nine-part structure
    refs.bib, refs_related.bib, refs_training.bib, refs_lifecycle.bib, refs_reroll.bib
  9_appendix/appendix.tex (observability / replayability ranking, Table tab:obsrank)
  bib/refs.bib (base entries) -> bib/refs_merged.bib (generated by build.sh from every */refs*.bib)
  build/ (pdflatex aux output, gitignored)
```

Per dataset: `<slug>.tex` is hand-written (template: `3_core/who_and_when/who_and_when.tex`, rules in `WRITER_GUIDE.md`);
`traj.tex` comes from `scripts/render_traj.py`, `figures/` from `scripts/make_figures.py ../notes ../report`;
`refs.bib` holds the corrected BibTeX entry. `main.tex` pulls a dataset in with `\dataset{<group>}{<slug>}`.
The slug -> group map lives in `scripts/report_layout.py`. Build with `./build.sh`.
