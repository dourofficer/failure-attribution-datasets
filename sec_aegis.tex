\begin{multicols}{2}
\paragraph{Description} AEGIS is the largest fully synthetic dataset in this survey, built for \emph{fine-grained error attribution}: given a failed MAS trajectory, predict the set of \textbf{(faulty agent, error mode)} pairs. It supports SFT, RL (GRPO with a hierarchical pair/agent/error reward) and contrastive learning on success/failure pairs; Aegis-Bench is the 600-trajectory test split (100 per benchmark). Construction:
\begin{itemize}
\item \textbf{Successful baselines} are run deterministically (all agents GPT-4o-mini, temperature 0) for six MAS on MASLab---LLM Debate, MacNet (chain/star/tree/full topologies), AgentVerse, DyLAN, SmolAgents, Magentic-One---over MATH, GSM8K, HumanEval, SciBench, MMLU-Pro and GAIA (GAIA only for the last two systems).
\item An LLM \textbf{adaptive manipulator} executes an injection plan, a set of (target agent, error modes), by \emph{prompt injection} (altering the agent's input) or \emph{response corruption} (replacing its output) through monkey-patched wrappers; corruptions are context-aware (plausible wrong arithmetic, infinite loops in code).
\item \textbf{Validation}: only runs whose final answer is wrong are kept; the injection plan becomes the label (refined post hoc for dynamic DyLAN graphs). Injection success: 76.5\% (Debate) down to 34.1\% (DyLAN).
\end{itemize}
\textbf{Taxonomy}: the 14 MAST failure modes---FM-1.1--1.5 specification issues (disobey task/role spec, step repetition, lost history, unaware of termination), FM-2.1--2.6 inter-agent misalignment (conversation reset, no clarification, derailment, withholding, ignored input, reasoning--action mismatch), FM-3.1--3.3 verification (premature termination, no/incorrect verification)---kept near-uniform by design (1,356--2,166 pairs each). \textbf{Quality check}: 100 Aegis-Bench trajectories blind-labelled by three experts, human--human Fleiss $\kappa$ = 0.85, programmatic-vs-human $\kappa$ = 0.81; MiniLM embeddings are interspersed with MAST-Data and Who\&When. \textbf{No step label}: the ground truth is agent + mode only, except that MacNet records flag every turn of an injected agent with \code{is\_injected}.

\paragraph{Metrics and baselines} Multi-label prediction of (agent, mode) pairs as JSON, scored by Micro-/Macro-F1 at three levels (Pair, Agent, Error); the paper averages 12 scores over Aegis-Bench and Who\&When (whose free-text reasons were mapped to FM modes by Gemini-2.5-Flash). \paragraph{Schema} \code{Aegis-Bench/test.jsonl}, \code{Aegis-Training/\{train,val\}.jsonl}, one object per line: \code{id} (\code{<Benchmark>\_<model>\_}\allowbreak\code{<framework>\_<idx>\_<hash>}), \code{metadata} (\code{framework}, \code{benchmark}, \code{model}, \code{task\_type}, \code{num\_agents}, \code{num\_injected\_agents}), \code{input.query}, \code{input.conversation\_history} (turns with 1-based \code{step}, \code{agent\_name}, \code{content}, \code{phase}; DyLAN adds \code{agent\_role}, MacNet \code{is\_injected}), \code{input.final\_output} (present in 83.5\%), \code{output.faulty\_agents} = labels \{\code{agent\_name}, \code{error\_type}, \code{injection\_strategy}\}, \code{ground\_truth.correct\_answer}, \code{ground\_truth.injected\_agents} (same pairs plus a short \code{malicious\_action\_description}), \code{ground\_truth.is\_injection\_successful} (always true).
\end{multicols}

\paragraph{Notes} (i) The only dataset here whose primary label is a \emph{set} of (agent, mode) pairs (mean 2.4, up to 4); no decisive step is annotated, so step-level attribution cannot be evaluated on AEGIS (MacNet's \code{is\_injected} flags every turn of an injected agent, not one step). (ii) Failures are fully synthetic, injected into GPT-4o-mini runs and shaped after MAST modes rather than naturally occurring slips; realism rests on $\kappa$ = 0.81 and embedding overlap. (iii) Short, homogeneous trajectories (median 10 turns, $\approx$5\,k tokens) with structural agent names. (iv) Data/paper discrepancies: per-framework and per-benchmark counts differ from the paper's Table 2 (e.g.\ AgentVerse 2,449 vs 1,995, Magentic-One 273 vs 449), pair total 22,701 vs 24,843; typos \code{smoagents}, \code{magentic+gaia}; a third strategy value \code{prompt} (273 pairs); \code{num\_injected\_agents} $\ne$ number of pairs in 22\% of records; two duplicated ids. (v) Shares Magentic-One/SmolAgents + GAIA with Who\&When, MAST and TracerTraj (shared author), but all runs are the authors' own; VerifyMAS (2026) reuses Aegis-Bench with a global/local/hybrid grouping of the modes. (vi) MIT licence and modest size make it the most convenient large training set in this survey.
