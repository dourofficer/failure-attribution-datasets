\paragraph{Description} AgentErrata is the evaluation set for AgentScope, a diagnosis method that abstracts a trajectory into a Reasoning--Action Graph and localises faults on it. It was built because Who\&When marks the failing step but has no failure-type label, and because---the authors argue---Who\&When's annotated step is often the \emph{earliest detectable} issue rather than the \emph{decisive} one. Trajectories come from three agent stacks, \textbf{OpenManus} (tool loop), \textbf{OWL} (two-agent user/assistant society) and \textbf{Mini SWE Agent}, on BrowseComp, SWE-bench Lite and WebArena; per-framework and per-benchmark counts are not given. Only \emph{successful} runs are kept; then taxonomy-guided \textbf{fault injection} is applied: an LLM first judges whether a run is suitable for a given mode, single-step faults are injected by instrumented replay at a chosen step, and faults with cross-step dependencies get extra post-processing to keep the text consistent. Every injected fault is decisive (the task fails). All 303 trajectories were \textbf{manually verified}, invalid ones discarded; annotator count, time and agreement are not reported. Labels per trajectory: the injected step and one of 10 modes in 3 categories:
\begin{itemize}
\item \textbf{Reasoning}: Wrong Context (WC), Instruction Unfollowing (IU), Insufficient Context (IC), Context Miss (CM);
\item \textbf{Control-flow}: Termination Miss (TM), Premature Termination (PT), Step Loop (SL);
\item \textbf{Action}: Action Mismatch (AM), Invocation Issue (II), Execution Failure (EF).
\end{itemize}
Whether an agent/role label exists is not stated.

\paragraph{Metrics and baselines} Fault localisation: step-level accuracy with tolerance (SLA T$\pm$0/1/3). Attribution: classification accuracy (CA, predicted mode = gold). Both reported with and without the reference solution; without solution, in \% (paper Tables 2--4):

\paragraph{Schema} Not available. The paper's internal representation is a DAG whose vertices are $\langle$id, role, content, ISR$\rangle$ with ISR = \{Intent \& Context, Reasoning \& Action, Signal \& Validation\}; node types: reasoning, action (tool call/output), user input, output, claim, tool response; edges: control and data dependencies. By analogy with Who\&When (benchmarked alongside), a release would hold steps with role/content, a \code{mistake\_step} and a mode label.

\paragraph{Example trajectory} The paper prints no AgentErrata record. Its only worked example (Appendix~C) is the Who\&When Hand-Crafted log \code{2.json}: Magentic-One (Orchestrator + WebSurfer) on a GAIA question about Ted Danson series, 86 steps, 103\,KB. Who\&When blames WebSurfer at step 4 (a bare search-results page); the paper reads this as an information gap and locates the decisive failure in the later stagnation loop (steps 11--85, two ``Stalled\ldots Replanning'' events at 37 and 64) and the final execution failure. \textbf{The trajectory below is long (86 steps)}; it is shown in full because the paper's argument is about where in it the decisive step lies, with the Who\&When label as the marked step.

\paragraph{Notes} (i) Nothing is public: no data, code or licence; all numbers above are paper-reported and a release would presumably be $\approx$303 JSON trajectories with a step index and one of 10 modes. (ii) Unique combination if released: injected decisive step + failure-mode label + manual verification, on mostly single-agent tool loops (OpenManus, Mini SWE Agent) rather than MAS. (iii) Taxonomy overlap with MAST (\S\ref{ds:mast_data}): SL $\approx$ FM-1.3, PT $\approx$ FM-3.1, TM $\approx$ FM-1.5, AM $\approx$ FM-2.6, IU $\approx$ FM-1.1; the Action category (II, EF) matches TRAIL's system-execution errors. (iv) Appendix~C's ``earliest detectable vs.\ decisive'' point applies to every human-labelled step dataset; in the cited file the run actually ends with ``FINAL ANSWER: CSI Cyber'', which matches the ground truth, yet it is labelled a failure---a label ambiguity in Who\&When itself. (v) Name clash: the AgentScope \emph{method} is unrelated to the \code{agentscope-ai} framework.
